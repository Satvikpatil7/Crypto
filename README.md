# Crypto Bucks

## Overview
Crypto Bucks is a cryptocurrency website built using **React.js**. It allows users to explore real-time cryptocurrency data with dynamic fetching and interactive price graphs. The website provides a user-friendly interface that showcases the latest cryptocurrency prices, trends, and market data.

## Features
- **Real-time Data**: Dynamic fetching of live cryptocurrency data from an API.
- **Price Graph Integration**: Interactive price graphs to visualize cryptocurrency trends in real time.
- **Responsive Design**: Fully responsive layout to ensure compatibility with all devices.
- **Routing**: Seamless navigation between different sections of the website, built with React Router.
- **API Integration**: Integrated third-party APIs for live cryptocurrency data fetching.

## Tech Stack
- **Frontend**: React.js, React Router
- **Libraries**: Axios (for API requests), Chart.js (for displaying real-time price graphs)
- **CSS Framework**: Tailwind CSS
- **Others**: JavaScript, HTML, CSS

## Installation

To get started with this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/crypto-bucks.git
   ```

2. Navigate to the project directory:
   ```bash
   cd crypto-bucks
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the project:
   ```bash
   npm start
   ```

5. Open the app in your browser at `http://localhost:3000`.

## Usage

- Visit the homepage to view the list of cryptocurrencies and their live prices.
- Click on a specific cryptocurrency to see more detailed information, including its real-time price graph.
- Navigate seamlessly between sections using the built-in routing.
